# 🗺️ Laboratório de Rotas: Algoritmo de Busca (Mini-Mapa)

Este repositório contém um projeto de laboratório focado no desenvolvimento e treinamento de algoritmos de busca e fundamentos de React. O objetivo é simular a lógica de um sistema de navegação *indoor* simplificado em JavaScript puro para solidificar os conceitos base antes da implementação oficial no meu Trabalho de Graduação (TG).

## 🎯 Objetivos do Estudo
* **Lógica de Algoritmos (Grafos):** Criar e percorrer rotas iterando sobre propriedades de objetos em JavaScript puro, simulando a conexão entre diferentes salas e corredores.
* **Fundamentos de React:** Compreender o uso do hook `useState` para controlar o estado da interface visual e promover atualizações na tela sem recarregar a página.
* **Manipulação de Dados:** Estruturar, importar e extrair informações mapeadas a partir de um arquivo de banco de dados estático (`mapa.json`).
* **Isolamento de Complexidade:** Focar estritamente na resolução do algoritmo de busca através do Vanilla JavaScript.

## 🛠️ Tecnologias Utilizadas
* **React (via Vite):** Renderização e reatividade da interface do usuário.
* **JavaScript (ES6+):** Lógica central para calcular o menor caminho entre os pontos.
* **JSON:** Estrutura de dados local (`mapa.json`) definindo os vértices e arestas do mapa (ID, nome, descrição e conexões).

## 🚀 Como executar este projeto
1. Clone este repositório na sua máquina.
2. Abra o terminal e acesse a pasta do projeto.
3. Instale as dependências executando o comando:
   `npm install`
4. Inicie o servidor de desenvolvimento:
   `npm run dev`
5. Segure o `Ctrl` e clique no link gerado no terminal para abrir o laboratório no navegador.
